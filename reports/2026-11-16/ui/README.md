# Photon modern workspace preview

Actual browser captures of the working investor sample, not UI mockups:

- [Desktop, light](desktop.png) — 1440 × 1000.
- [Desktop, dark](dark.png) — 1440 × 1000.
- [Phone, guide collapsed](mobile.png) — 390 × 844.

All use a fresh browser context and synthetic presentation data. Existing user
projects are not shown. This is the feature build; no production promotion is implied.

The design retains the existing editor, navigation handlers, project storage,
annotation geometry and export operations. A stylesheet and a presentation-only
module add the workspace shell, real save status, labeled icons, responsive menus
and a collapsible guide. No external fonts, icon library or framework is required.
